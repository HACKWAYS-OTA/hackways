# Additional event fonts

Sources: [Google Fonts](https://github.com/google/fonts/tree/main/ofl) and its fonts.googleapis.com CSS2 delivery API. Files are original regular-weight Latin WOFF2 subsets, downloaded on 2026-10-22. Each corresponding *-OFL.txt license is included. Other scripts use the existing fallback fonts.

Families: DM Sans, Manrope, Space Grotesk, Outfit, Sora, Fraunces, Playfair Display, Lora, DM Mono, Bebas Neue. The combined ten WOFF2 files total 160,012 bytes; browsers load only the selected face. Public-web carries the same files because root /fonts requests are served by the public service under the existing Nginx configuration.
